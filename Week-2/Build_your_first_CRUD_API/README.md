## Objective

This assignment focuses on building a RESTful CRUD API using FastAPI. The goal is to understand how backend APIs handle Create, Read, Update, and Delete operations while working with request validation, HTTP methods, status codes, and automatic API documentation using Swagger UI.

## Contents

- app.py
- requirements.txt
- README.md
- Swagger-Testing.pdf

## Outcome

Through this assignment, I built my first CRUD API using FastAPI. The API supports creating, retrieving, updating, and deleting tasks stored in an in-memory list. While building this project, I learned how REST APIs are structured, how different HTTP methods are used, how request validation works with Pydantic models, and how to test APIs using FastAPI's built-in Swagger documentation. This assignment also helped me understand the overall workflow of backend API development, which will be useful when I start learning Java Spring Boot in the future.
