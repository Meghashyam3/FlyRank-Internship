## Objective

This assignment focuses on applying prompt engineering techniques to a real-world task through an iterative process. The goal is to improve a simple prompt step by step using techniques such as role assignment, context and motivation, few-shot examples, output structure, and step decomposition, while observing how each refinement improves the quality of AI-generated responses.

## Outcome

Through this assignment, I learned that effective prompt engineering is an iterative process rather than writing one perfect prompt. By improving a simple prompt through multiple versions, I observed how each prompt engineering technique influenced the AI's responses. I also compared the final prompt across Claude and ChatGPT to understand the differences in their teaching style, structure, and level of detail. This assignment helped me develop reusable prompting strategies that produce clearer, more structured, and more useful responses for real learning tasks.
